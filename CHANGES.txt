IW4x-32 v1.1 - complete list of changes (player build)
============================================================
Plain text on purpose, for people and for AI assistants. Every changed byte is in source/manifest_iw4x_exe.json
and source/manifest_iw4x_dll.json; source/iw4x32_check.py verifies both against your own official IW4x files.

WHY
  MW2's engine and IW4x size everything per-player for 18 players (MAX_CLIENTS = 18): arrays of player info, loop
  bounds, 'is this entity a player' checks (entity numbers 0..17 = players, 18..25 = dead bodies). On a 32-player
  server players 19-32 would be invisible, missing from the scoreboard/minimap, or overwrite memory. The changes
  below give the CLIENT room and logic for 32 players. Server-side (hosting) code is not changed: a server started
  with these files is limited to 18 players (stock sv_maxclients range 1..18).

FILES
  iw4x.exe: built from the official file sha256 49ea90e34c9cd64d9d0ae7f4b399e4ecc5ea13976823b2b8667390a4b8767009 (md5 9c42ffa4f7aefd08fd501b40f5e41eab)
            ours: sha256 2609c2687dd2ffb3f32c7687ed04f57b38ef6879c14b1c546faf8bfd8f35ea6b, 22517 bytes changed in 617 places
  iw4x.dll: built from the official file sha256 82819f1a0c8e3758af8acb8773dc2e2f5cc069202b995e79772a23c9551236cd (md5 c5d73b3ec5e4b36e284a4ae0cfc7fb13)
            ours: sha256 57f1189ebfcb6a6acc7338311e862a7fa0974a5242c5991e6f1267a17afb3cef, 109 bytes changed in 37 places
  Official files = IW4x r5154 (protocol 153). The official iw4x.exe of r5154 is the same file IW4x has shipped since r5121.

SAFETY FACTS (checked by source/iw4x32_check.py)
  - The import tables (Windows functions each file can call) are byte-identical to the official files.
  - No network code, file access or process access was added. The added code calls only game functions and
    VirtualProtect (looked up through the game's own GetProcAddress) to rewrite 16 code sites in its own exe.
  - One behaviour change besides 32 players: the IW4x 'update available' notice is never set (see DLL D3).

E6  What the injected code does (source/engine32c/compat.c)
    - registers a read-only userinfo dvar iw4x32=1 so 32-player servers can tell your game has IW4x-32;
    - when the game parses a server's info (CG_ParseServerinfo) it reads sv_iw4x32: if the server is a normal
      18-player IW4x server, the 16 [S] sites are written back to their original bytes (normal player/body layout);
      on a 32-player server our bytes are restored. This uses VirtualProtect on those exact addresses only;
    - Session_* guards: player slots >= 18 are kept out of the 18-entry party/session tables (no overflow);
    - if you start a (max 18-slot) server yourself it always uses the normal layout.
