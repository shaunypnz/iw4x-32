# IW4x-32 updater channel

This branch only holds `latest.json`, which the IW4x-32 auto-updater on players' PCs reads. The project itself
lives on the default branch, [`iw4x-32`](https://github.com/shaunypnz/iw4x-32/tree/iw4x-32).

Current version: **v1.2** (its files are served from [iw4x-32-old](https://github.com/shaunypnz/iw4x-32-old)).
v2.0 (one `iw4x.dll`, no patched `iw4x.exe`) will be published here when it is ready.
