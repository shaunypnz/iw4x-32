IW4x-32 - who did what (people and AI models)
================================================

This mod was built by one person with AI assistants. Nothing an AI model produced was used unchecked: every
address, patch site and claim was verified against the engine and in live tests before it went into a build,
and the build aborts if any expected address or original byte does not match.

PROJECT OWNER (human)
  - Idea, goals and decisions; play-testing on real PCs; hosting; release.

CLAUDE (Anthropic, run in Claude Code) - lead engineer
  - v1.0-v1.2: reverse engineering of MW2 / IW4x - found the 18-player limits in iw4x.exe and iw4x.dll
    (per-player arrays, loop bounds, "entity number < 18 = player" checks, snapshot and voice limits, minimap,
    scoreboard), wrote the tools that patched the official files and the injected C/asm code, the manifests and
    the checker, the installers, and the automated test rig (dedicated server + bots + a real client under Wine).
  - v2.0: moved that work into the IW4x source as a normal component: the engine tables, the in-memory patcher,
    the 18/32 layout switch and the lag-compensation rewrite in src/Components/Modules/IW4x32.cpp; reviewed and
    re-tested everything the models below produced.

QWEN (Alibaba Qwen, run locally) - analysis and build assistant
  - v1.x: minidump analyser, engine symbol map and cross-reference tool, first-pass triage of the per-player
    arrays and of every "18" constant in the exe, the minimap actor table, porting patch sites from IW4x r5121 to
    r5154 by byte signature, the renderer's skinned-vertex cache (invisible player models), reference audits,
    and the split between sites that switch layout and sites that do not.
  - v2.0: the engine patch tables and the in-memory patcher in the fork (generated tables + component), the
    player kit and the release workflow, and the Wine build of the whole IW4x source with MSVC.

GEMMA (Google gemma, run locally) - documentation assistant
  - Run-summary tool for test logs; stale-claim finder for the project notes; first drafts of the release
    readme, compatibility notes and hosting guide. All drafts were checked and rewritten where needed.

OFFICIAL SOFTWARE THIS IS BASED ON
  - Call of Duty: Modern Warfare 2 (Activision / Infinity Ward).
  - IW4x r5154 (https://github.com/iw4x/iw4x-client, GPL-3.0). The iw4x.dll in this kit is built from a fork of
    that source with the IW4x-32 commits on top; the fork is the complete source of the changes.
